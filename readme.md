# Fitzwilliam AI Circle — Labs

Hands-on labs from the Fitzwilliam AI Circle. Each subdirectory is a self-contained lab from one month of the Circle.

| Lab | Month | What you do |
|---|---|---|
| [gpt2-tinygrad](gpt2-tinygrad/) | GPT-2 from scratch | Implement GPT-2 in [tinygrad](https://github.com/tinygrad/tinygrad), train it on TinyShakespeare, sample text. |
| [scaling-lab](scaling-lab/) | Scaling | Reproduce the scaling-laws result on real [nanochat](https://github.com/karpathy/nanochat) runs, then forecast a held-out model in a prediction contest. |

Each lab folder has its own `readme.md` with setup instructions, lane choices, and what to bring on the day.
